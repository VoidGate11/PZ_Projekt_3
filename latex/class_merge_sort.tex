\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class Merge\+Sort$<$ T $>$}
Szablonowa klasa sortujaca tablice metoda dziel i zwyciezaj (Merge Sort). 

Klasa pozwala na sortowanie tablic dowolnego typu liczbowego (np. int, long int, float, double), o ile typ ten wspiera operatory porownania (\texorpdfstring{$<$}{<}=) oraz przypisania (=).
